## Day 1 ｜ 2026-09-15 ｜ 立项 + 方案 + 原型

**背景**：课程实训要求开发一个小程序作为大作业。决定复用现有 YUMU 社区后端，做「社区附带的小程序」。

**当天完成**

1. **可行性与约束核实**（决定方向的前提，先查再设计）
   - 核实后端公开接口范围：`/games`、`/posts`、`/search`、`/tags`、`/announcements`、`/picks`、`/stats`、`/boards`、`/files` 全部 `permitAll` ⇒ **浏览内容无需登录**，后端零改动。
   - 核实「视频」相关代码：**全项目零命中** ⇒ 帖子只支持图片，视频属于从零做。
   - 查证小程序平台限制：个人主体**不可用 `web-view`**（无法内嵌 B 站）。
   - **实测分页参数**：`page=2` 被静默忽略、恒返回第 1 页；**真正生效的是 `current`**。这个坑若不提前查出来，「上拉加载更多」会无限重复第一页且不报错。
   - 实测线上 `GET /announcements` 与 `GET /picks/daily` 当前返回**空数组** ⇒ 资讯主线改用 `/posts?boardId=4`（资讯速递，24 条真实内容）为主数据源。

2. **方向确认**（用户已选）
   - 方向：**攻略 + 资讯 双主线**（游戏库导航 → 游戏页分「攻略 / 资讯」双 Tab → 详情步骤卡）。
   - 技术形态：**uni-app**（理由：与社区前端同栈；一套代码可同时产出小程序 + H5，H5 版能挂现有服务器，绕开备案域名限制）。

3. **产出**
   - `docs/方案设计.md`：定位 / 范围界定（做与不做）/ 7 页页面结构 / **接口映射表** / 技术方案 / 关键实现设计 / 平台限制与应对 / 6 步开发计划 / 风险待确认。
   - `prototype/index.html`：6 屏移动端原型（首页 / 游戏库 / 游戏主页 / 攻略详情 / 资讯 / 我的），视觉延续深色 + YUMU 紫，内容全部取自线上真实数据。
   - **核心亮点设计**：攻略步骤卡 —— 把现有「一整段长文」的攻略在前端解析成「第 1 步 / 第 2 步 / 第 3 步」卡片。**解析放在前端做，后端一行不改**，既有内容零迁移成本。

4. **目录归置**：确立 `docs/`（文档）+ `prototype/`（原型）+ `src/`（源码）三层结构，本子项目独立成文件夹。
