# 把「网页版」挂到微信里 —— 三条路线与操作步骤

> 2026-09-25 整理。场景：**不备案，只当作业 / 答辩展示**。
> 结论先行：**不备案能走通两条路（A / B），第三条（正式发布）现在走不通，别在上面花时间。**

---

## 0. 先看这张表

| 路线 | 能在微信里打开吗 | 要备案吗 | 谁看得到 | 大概耗时 | 推荐度 |
|---|---|---|---|---|---|
| **A. 链接 / 二维码直开 H5** | ✅ 能 | ❌ 不用 | 你把码发给谁，谁就能看 | 5 分钟 | ⭐⭐⭐ 作业展示首选 |
| **B. 小程序「体验版」+ 手机开调试** | ✅ 能，且**像真小程序** | ❌ 不用 | 只有你加进「体验成员」的人 | 1～2 小时 | ⭐⭐ 想演示"小程序形态"时用 |
| **C. 正式发布上架** | —— | **✅ 必须** | 全微信用户 | 2～4 周 | ❌ 本阶段不做 |

**两条路都不需要备案，也都不需要买域名。**

## 路线 A：二维码 / 链接直接打开（推荐）

### 为什么可行
小程序的那套「服务器域名必须 HTTPS + 已备案」限制，**只管小程序**。
微信里直接打开一个网页（H5）走的是微信内置浏览器，不受小程序域名白名单约束。

### 操作步骤
1. 拿现成的二维码：`docs/展示二维码-H5版.png`（内容就是 `http://8.133.255.202/m/`）。
   要改链接就自己再生成一个，或用微信「扫一扫」下面的"生成二维码"。
2. 把二维码图片 / 链接**发到微信聊天、群、或直接给对方扫**。
3. 对方点开后就是完整的 H5 版（攻略 / 资讯 / 游戏库 / 搜索 / 详情都能用）。

### 要注意的三件事（都是真实存在的限制，不是 Bug）
| 现象 | 原因 | 怎么办 |
|---|---|---|
| 打开时可能弹「非官方网页 / 存在安全风险」提示 | 你是 **http 明文 + IP**，不是 https 域名 | 点「继续访问」即可，正常现象 |
| **分享到朋友圈**次数多了会变成"仅自己可见" | 微信对**未备案域名**的朋友圈分享频率有限制（官方客服 FAQ 明确写了） | 作业展示**发聊天 / 群就够**，别走朋友圈 |
| 微信可能缓存旧页面 | 内置浏览器缓存 | 右上角 `···` → 刷新 |

> ⚠️ 建议**答辩前用自己的手机实测一遍**（微信内打开 + 点几个页面 + 看图片是否加载）。
> 我们的回归测试跑的是 Chromium，**不等于微信内置浏览器**，没在微信里真开过就不算验证过。

## 路线 B：小程序「体验版」+ 手机开调试（免备案）

### 为什么可行（关键前提）
微信官方文档原文：

> 在微信开发者工具中，可以临时开启「开发环境不校验请求域名、TLS 版本及 HTTPS 证书」选项…此时，
> **在微信开发者工具中及手机开启调试模式时，不会进行服务器域名的校验。**

也就是说：**手机上把"调试"打开之后，域名校验会整体关掉**——`http://8.133.255.202` 这种 IP + HTTP 就能直连。
这条对 **开发版 / 体验版** 有效，**正式版无效**（调试开关对普通用户不可见）。

> 📌 所以本文件更正了 `README.md` 里旧的那句「❌ 不做体验版（仍需 HTTPS 已备案域名）」——
> **结论过严了**：体验版并不需要备案，真正需要的只是"每个体验成员手动开一次调试"。

### 前置条件
- 微信开发者工具（稳定版即可）
- 一个**已注册的小程序 AppID** —— 本机 `miniprogram/.env.local` 里已经有（`WX_APPID=wxae31…`）
- 该微信号是这个小程序的**管理员或开发者**（否则后台传不上去）

### 操作步骤

```bash
# 1. 注入 AppID（.env.local → manifest.json，只写本机，不进 Git）
cd miniprogram
npm run appid:inject

# 2. 出 mp-weixin 产物
npm run build:mp-weixin        # 产物目录：dist/build/mp-weixin
```

3. 打开**微信开发者工具** → 导入项目 → 目录选 `miniprogram/dist/build/mp-weixin`，
   AppID 会自动读 `project.config.json` 里的（或手填）。
4. **详情 → 本地设置** 勾选：`不校验合法域名、web-view（业务域名）、TLS 版本以及 HTTPS 证书`。
5. 模拟器里先点一遍（攻略 / 资讯 / 详情），确认接口都通。
6. 点工具栏 **「上传」**，填版本号（如 `1.0.0`）和备注。
7. 打开 `mp.weixin.qq.com`（用管理员微信扫码）→ **管理 → 版本管理** → 在「开发版本」里找到刚传的版本
   → **「选为体验版」**。
8. **成员管理 → 体验成员** → 添加老师 / 同学的微信号。
   （有数量上限，添加时后台会提示当前额度，一个班够用。）
9. **版本管理 → 体验版 → 查看二维码** → 把体验版二维码发给他们。
10. 他们扫码就能在微信里以**小程序的形态**打开。

### 🚨 三个必踩的坑

1. **每个体验成员首次打开都必须手动开一次调试**，否则所有接口全挂（页面空、提示网络异常）：
   > 打开小程序 → 右上角 `···` → **开发调试** → **打开调试** → 按提示重启小程序
   > （部分微信版本这一项直接叫「打开调试」。开成功后页面顶部会出现调试标识。）

   这一步替代不了 —— 因为 `http://8.133.255.202` 不是合法 HTTPS 已备案域名。
2. **用完必须还原 AppID**，否则工作区脏、发版会被拒：
   ```bash
   npm run appid:restore
   ```
3. **主包体积 ≤ 2MB**。本项目图片全在服务器上（走接口 URL），包体应该很小；
   如果上传报超限，先查是不是把 `dist_bak*/` 之类误放进去了。

### 🚨 首次编译报「编译 .wxss 文件错误」？（2026-09-25 已修，记一下怎么查的）

第一次导入产物的经验：模拟器整个白屏，弹层写着

> 编译 .wxss 文件错误，错误信息如上，可在控制台查看更详细信息

**注意：这句话本身不带任何线索，真正的原因在开发者工具的「Console」标签页**（默认停在 Wxml/Elements 面板，所以看不见）。

**根因**：微信 WXSS 编译器**不支持通配符选择器 `*`**。项目里有 5 处 `.xxx > *`（当初为压住 H5 端 `uni-text` 自带的 `white-space: pre-line` 才写的），
H5 浏览器认这个写法，微信编译器直接拒收 ⇒ **小程序端编译不过，H5 端却一切正常**，所以之前 H5 回归全绿也发现不了。

**怎么定位的（可复用）**：微信开发者工具自带编译器，直接拿它对产物逐个跑即可，不用靠猜：

```bash
W="/e/微信web开发者工具/resources/app.asar.unpacked/node_modules/wcc-exec/wcsc.exe"
cd miniprogram/dist/build/mp-weixin
for f in $(find . -name "*.wxss"); do "$W" "$f" 2>&1 >/dev/null; done
# 输出形如：  ERR: components/PostCard.wxss(1:1399): error at token `*`
```

**怎么修的**：这条规则本来就**只对 H5 有意义**（小程序端 `<text>` 是原生标签，没有 `pre-line` 问题），
所以用条件编译把它圈起来，两个端各取所需：

```css
/* #ifdef H5 */
.pc__meta > * { white-space: nowrap; }
/* #endif */
```

涉及 5 个文件：`components/PostCard.vue`、`components/PlatformFilter.vue`、`pages/post/detail.vue`、
`pages/my/my.vue`、`pages/games/games.vue`。**改完复跑上面的 wcsc 命令，0 报错才算过。**

## 路线 C：为什么不走正式发布

正式发布（能被所有人搜到）要依次过四道关，**任何一道都卡死**：

| # | 关卡 | 本项目状况 |
|---|---|---|
| 1 | 服务器域名必须是 **HTTPS** | 只有 `http://8.133.255.202`，❌ |
| 2 | 服务器域名**不能是 IP** | 同上，❌（微信明文规定不接受 IP） |
| 3 | 域名 **ICP 备案** | 没做，❌ |
| 4 | **小程序 ICP 备案** | 2023-09 起是发布前置条件，没做，❌ |

所以：**「完成小程序端开发 + H5 版部署上线」是当前准确口径**，别说成「小程序已上架」。

- 微信开放文档《申请测试号》：
  > 在真机上如需跳过网络请求域名的校验，需要点击右上角选项，选择「打开调试」即可。

- 腾讯客服《微信访问网站被限制的相关问题》：
  > 未备案域名，分享达一定次数后，再分享将仅自己可见。
